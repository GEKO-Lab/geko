# GEKO Portfolio

Portfolio-Website mit Three.js-Hintergrund, Diagonal-Scroll und GEKO-Farben (Lila, Pink, Orange, Gelb).

## Website live ansehen (nicht diese README-Seite!)

Die **echte Website** ist hier:

### https://geko-lab.github.io/geko/

> **Hinweis:** Auf `github.com/GEKO-Lab/geko` siehst du nur den Quellcode und diese README.
> Die Portfolio-Website öffnest du über den Link oben.

Falls die Seite noch nicht lädt: **Repository → Settings → Pages → Branch: `gh-pages` / `/ (root)`** wählen und speichern.

## Lokal starten

```bash
cd web
npm install
npm run dev
```

Dann öffnen: **http://localhost:5173/geko/**
