# GEKO Portfolio

Portfolio-Website mit Three.js-Landschaft (Wasserfall, Scroll-Parallax) und GEKO-Farben (Lila, Gelb, Orange).

## Lokal starten

```bash
cd web
npm install
npm run dev
```

## Online

Nach Push auf `main` wird die Seite automatisch auf **GitHub Pages** deployed:

**https://geko-lab.github.io/geko/**
